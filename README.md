# Satbayev Finance Club — Open Lecture Landing

Static GitHub Pages landing page for the open lecture on 24 November 2026.

## Features
- Responsive Russian-language landing page
- Live countdown to 24 November 2026, 18:30 (Asia/Almaty, UTC+5)
- Personal invitation card generator and PNG download (runs locally in the browser)
- Google Calendar prefilled event link
- Apple Calendar / Samsung Calendar .ics download with selectable VALARM reminder
- No backend, database, registration, or collection of visitor contact details

## Event details
- Date: Tuesday, 24 November 2026
- Time: 18:30–20:00, Almaty time
- Venue: Satbayev University, 22 Satpaev Street, Almaty, Kazakhstan
- Auditorium: TBA

## Publish
Repository Settings → Pages → Build and deployment → Deploy from a branch → Branch: main → Folder: /(root) → Save.

## Calendar notes
Google Calendar opens a prefilled event form; the visitor must save it and verify the notification setting. Apple/Samsung calendar support uses an ICS file with the selected VALARM reminder. The exact notification behavior depends on the calendar app and device settings.
